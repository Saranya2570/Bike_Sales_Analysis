# 🚲 Bike Sales Analysis – Excel Data Analytics Project

## 📌 Overview

This project analyzes **1,026 customer records across 13 columns** using **Microsoft Excel** to identify bike purchasing patterns and customer trends.

The project covers **data cleaning, data analysis, Pivot Table analysis, customer segmentation and dashboard development**.

The final cleaned dataset contains **1,000 records across 14 columns**, including an **Age Brackets** field created for customer segmentation.

---

## 📂 Dataset

**Original Dataset:** 1,026 rows × 13 columns
**Cleaned Dataset:** 1,000 rows × 14 columns

The dataset contains customer demographic and bike purchase information.

**Key Columns:**
Customer ID, Gender, Age, Income, Marital Status, Education, Occupation, Number of Cars, Commute Distance, Region, Purchased Bike, Age Brackets.

## 🚀 Project Workflow

### 1. 🧹 Data Cleaning

* Checked and standardized the raw dataset.
* Removed unnecessary records.
* Created an **Age Brackets** column for customer segmentation.
* Prepared the final analysis-ready dataset.

### 2. 🔍 Data Analysis

Analyzed bike purchasing patterns based on **Age, Gender, Income, Commute Distance, Education, Occupation, Region and Number of Cars**.

### 3. 📊 Pivot Table Analysis

Created Pivot Tables to summarize customer segments and analyze bike purchasing behavior.

### 4. 📈 Dashboard Development

Created an interactive Excel dashboard using charts and visualizations to present key customer and purchasing patterns.
